## Overview

LMNx9 web2app turns any live URL into a native Android WebView APK.  
Custom branding, permissions, offline fallback and signed output — all from one builder.

| | |
| :--- | :--- |
| Version | `v1.2` |
| Type | Website to APK |
| Output | Signed Encrypted APK |
| Stack | HTML · JS · CSS · PHP |
| Author | [DARK LMNx9](https://t.me/x_LMNx9) |

## Features

```
⊞  One-Click Website to Signed Encrypted APK
⊞  Custom App Name, Package and Version
⊞  Portrait, Landscape and Auto Orientation
⊞  Custom Logo, Splash, Theme and Status Bar
⊞  10+ WebView Advanced Controls
⊞  Custom Offline Page HTML Support
⊞  10+ Runtime Permission Support
⊞  Pull Refresh, Swipe Nav and Confirm Exit
⊞  Config JSON Export & Build History Search
```

---

## Quick Start

1. Open the builder
2. Paste your website URL
3. Set name, package, logo and theme
4. Toggle options and permissions
5. Hit **BUILD APK** and install
